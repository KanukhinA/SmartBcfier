# SP-BCFier

Плагин Autodesk Revit и автономный Windows Viewer для работы с замечаниями в формате [BCF](https://github.com/buildingSMART/BCF-XML). Форк [BCFier](https://github.com/teocomi/BCFier) с поддержкой современных версий Revit, BCF 3.0 и доработками под ежедневную работу с замечаниями.

В интерфейсе продукт отображается как **«Замечания BCF»**.

| | |
|---|---|
| **Revit** | 2022, 2023, 2025, 2026 |
| **Windows Viewer** | автономное приложение без Revit |
| **BCF** | чтение 1.0–3.0, запись 2.1 или 3.0 |
| **Языки** | русский, английский |
| **Версия** | 1.0.19 |

---

## Возможности

### Общие (Revit и Windows Viewer)

- Создание, открытие, сохранение и объединение отчётов `.bcf` / `.bcfzip`
- Drag and drop файлов, несколько отчётов во вкладках
- Замечания: статус, тип, приоритет, метки, исполнитель, срок, описание
- Виды (viewpoints): снимок, комментарии, список компонентов
- Настройки автора, списков статусов/типов и версии записи BCF
- Два режима отображения: **карточки** и **таблица**
- [Пользовательские поля](#пользовательские-поля) уровня отчёта
- Экспорт в **Excel**, **HTML** и **PDF**, импорт замечаний из **Excel**

### Только Revit

- Снимок с 3D-вида, привязка элементов, граница 3D (Section Box) сохраняется в стандартные плоскости обрезки BCF
- Замечание с плана, разреза или фасада: в файл пишется и стандартная 3D-камера с обрезкой (чтобы открыть то же место в BimCollab или в другой модели), и ссылка на исходный вид Revit (чтобы в этой же модели снова открыть именно план/разрез). Подробнее: [отклонения от схемы BCF](#отклонения-от-схемы-bcf)
- Выбор и выделение элементов модели, сопоставление по Id / IfcGuid
- Фильтр «только замечания активного документа»
- Режимы координат: Revit Z-up, Source Y-up, Source X-up

### Windows Viewer

- Просмотр и редактирование BCF без установленного Revit
- Добавление видов из файла изображения (Browse / drag and drop)

### Типичный сценарий (Revit)

1. Откройте панель **«Замечания BCF»** на ленте Revit.
2. Создайте или откройте BCF-файл.
3. Добавьте замечание или вид с текущего 3D-вида (снимок, элементы, section box).
4. Заполните статусы и комментарии.
5. Сохраните `.bcf` / `.bcfzip` и передайте коллегам: при открытии viewpoint восстанавливаются камера, section box и выделение.

Настройки хранятся в `%LocalAppData%\BCFier\settings.config`.

## Табличный режим

Кнопка **«Таблица»** в верхней панели переключает отображение между карточками и таблицей. В таблице каждое замечание — строка, а поля BCF редактируются прямо в ячейках.

### Колонки

Кнопка **«Колонки»** открывает настройку состава и порядка колонок. Для каждой доступны:

- видимость и порядок (кнопки «Вверх» / «Вниз»);
- собственный заголовок вместо стандартного (например `Наименование вопросов` вместо `Заголовок`);
- выравнивание текста — по левому краю, по центру, по правому.

Доступные колонки: заголовок, описание, статус, тип, приоритет, исполнитель, стадия, метки, срок, автор и дата создания, автор и дата изменения, индекс, GUID, снимок, **описание + снимок**, **заголовок + снимок**, комментарии.

Колонки вида «+ снимок» показывают галерею всех снимков замечания (BCF допускает несколько viewpoint на тему) и кнопку добавления ещё одного вида. Клик по миниатюре открывает снимок, в Revit — восстанавливает вид.

### Колонки комментариев

Колонку комментариев можно добавить несколько раз, у каждой свой охват:

| Охват | Что попадает в ячейку |
|-------|------------------------|
| Все | все комментарии замечания |
| Пользователь | комментарии одного автора |
| Группа | комментарии участников выбранной группы |

Группы пользователей задаются в том же окне: имя группы и список участников. Это позволяет, например, держать рядом колонки «Замечания подрядчика» и «Ответ проектировщика».

### Работа со строками

- **«Добавить замечание»** — новая строка прямо в таблице.
- Правый клик по строке → **«Удалить замечание»**.
- Замечания без координат (viewpoint без камеры) подсвечиваются в списке — такие пункты не откроются в модели.

## Пользовательские поля

Поля уровня **всего отчёта** (не отдельного замечания): дата, участники и т.п. для шапки протокола.

1. **Каталог** — в настройках задаётся список доступных полей: имя и тип (`Текст` или `Дата`). Имена уникальны.
2. **В отчёт** — кнопка **«Пользовательские поля»**: отметить нужные из каталога (повторно то же поле не добавить).
3. **Значения** — в карточном режиме под заголовком, в табличном — в панели над таблицей и в окне **«Оформление»**.
4. **В протоколе** — при экспорте в HTML/PDF поля идут над таблицей замечаний, с группировкой по блокам (см. [экспорт](#html-и-pdf--протокол-совещания)).

Как это записано в файле BCF (вне схемы) — в разделе [отклонения от схемы BCF](#documentscustom-fieldsxml).

## Экспорт и импорт

### Excel

Экспорт пишет `.xlsx` с видимыми колонками, переносом текста и встроенными снимками.

Импорт (**«Excel»**) открывает окно сопоставления: лист, признак строки заголовков и соответствие «колонка Excel → поле BCF». Сопоставлять можно поля, включённые в таблице, плюс заголовок. Картинки из ячеек листа становятся снимками замечаний.

### HTML и PDF — протокол совещания

1. Заголовок документа (до двух строк).
2. Блоки [пользовательских полей](#пользовательские-поля) — таблицы «подпись — значение».
3. Таблица замечаний со снимками.

Оформление — кнопка **«Оформление»** в табличном режиме:

| Настройка | Назначение |
|-----------|------------|
| Заголовок документа | Первая строка шапки; пусто — имя отчёта |
| Вторая строка заголовка | Например `совещания по отделке объекта` |
| Выводить пользовательские поля над таблицей | Включает блоки шапки |
| Колонка «№ п/п» | Нумерация строк |
| Поля шапки | Порядок, значения и **блок** (группа под общим заголовком, например `Участники:`) |

Шапка протокола и поля сохраняются в `Documents/custom-fields.xml` — см. [отклонения от схемы](#documentscustom-fieldsxml).

## Отклонения от схемы BCF

Что SP-BCFier пишет **сверх** [BCF-XML](https://github.com/buildingSMART/BCF-XML/tree/release_3_0/Documentation). У каждого пункта — зачем.

### `SheetCamera`

**Зачем:** в схеме нет «открой этот план/разрез/лист в Revit». Без ссылки на вид плагин не вернёт исходный 2D-вид с тем же зумом в той же модели.

**Что сделано:** необязательный элемент вне схемы внутри `VisualizationInfo`:

```xml
<SheetCamera>
  <TopLeft><X>…</X><Y>…</Y><Z>…</Z></TopLeft>
  <BottomRight><X>…</X><Y>…</Y><Z>…</Z></BottomRight>
  <SheetID>123456</SheetID>
  <SheetName>Имя вида Revit</SheetName>
</SheetCamera>
```

| Поле | Зачем |
|------|--------|
| `SheetID` / `SheetName` | Найти вид в проекте |
| `TopLeft` / `BottomRight` | Восстановить зум |

Чужие программы элемент обычно пропускают.

### Стандартная камера и обрезка вместе с `SheetCamera` (план / разрез / фасад)

**Зачем:** `SheetCamera` другим клиентам бесполезен. Чтобы замечание с плана/разреза открывалось в BimCollab (и в другой модели Revit) в том же месте и с той же подрезкой, нужны обычные поля схемы.

**Что сделано:** для плана, разреза, фасада и плана несущих дополнительно пишутся `OrthogonalCamera` и при наличии секущего диапазона — `ClippingPlanes`. Для листа и чертёжного вида — только `SheetCamera`.

### `Documents/custom-fields.xml`

**Зачем:** в схеме BCF нет полей уровня всего отчёта (шапка протокола). Их нельзя положить в `markup.bcf` / `.bcfv` без ломки совместимости.

**Что сделано:** отдельный файл в `Documents/` внутри архива. Канонический вид при сохранении:

```xml
<?xml version="1.0" encoding="utf-8"?>
<CustomFields>
  <Document Title="ПРОТОКОЛ №27 от 18.02.2026г."
            Subtitle="совещания по отделке объекта"
            ShowFieldBlocks="true"
            ShowRowNumbers="true" />
  <Report>
    <Field Id="a1b2c3" Name="Дата:">18.02.2026</Field>
    <Field Id="d4e5f6" Name="Время:">13:30</Field>
    <Field Id="7a8b9c" Name="Заказчик:" Section="Участники:">Иванов В.А., Петров И.В.</Field>
  </Report>
</CustomFields>
```

| Элемент / атрибут | Назначение |
|-------------------|------------|
| `<Document>` | Оформление протокола. Необязателен |
| `<Report>` | Контейнер полей отчёта |
| `<Field>` | Одно поле; текст элемента — значение |
| `Id` | Id в каталоге; по нему подставляется актуальное имя из настроек |
| `Name` | Имя, если `Id` пуст или не найден в каталоге |
| `Section` | Заголовок блока в протоколе; пусто — блок без заголовка |

Нужен хотя бы один из `Id` / `Name`.

При открытии сканируются все `*.xml` в корне `Documents/`. Кроме канонического формата читаются:

- `<Field>` сразу под `<CustomFields>` (без `<Report>`);
- устаревшие поля внутри `<Topic>` — поднимаются на уровень отчёта;
- плоский «ключ — значение» (любой корень с простыми дочерними элементами):

```xml
<ProjectInfo>
  <Дата>18.02.2026</Дата>
  <Время>13:30</Время>
  <Место>ВКС/Штаб строительства</Место>
</ProjectInfo>
```

Правила: дубликаты по `Id` (или по `Name`, если `Id` пуст) отбрасываются; ошибка разбора не ломает открытие отчёта. При сохранении всегда пишется канонический `custom-fields.xml`; если полей нет и оформление не менялось — файл удаляется.

Работа с полями в интерфейсе — [пользовательские поля](#пользовательские-поля).

## Установка

### Установщик (рекомендуется)

1. Закройте Revit (если ставите add-in).
2. Запустите `dist\BCFier-SP-1.0.19-Setup.exe`.
3. Выберите компоненты:
   - **Add-in for Autodesk Revit 2022 / 2025**
   - **BCFier for Windows** (просмотр BCF без Revit)
4. Для Revit: запустите Revit, на ленте появится панель **«Замечания BCF»**.
5. Для Viewer: ярлык в меню «Пуск» (и опционально на рабочем столе) → `BCFier.Win.exe`.

Установка per-user, права администратора не нужны.

| Компонент | Куда ставится |
|-----------|----------------|
| Revit add-in | `%AppData%\Autodesk\Revit\Addins\{год}\` |
| Windows Viewer | `%LocalAppData%\BCFier-SP\` |

Исходник установщика: [`InnoSetup/SP-BCFier.iss`](InnoSetup/SP-BCFier.iss).

### ZIP / ручная установка

**Revit add-in** — архивы и папки в `dist\`:

- `BCFier-SP-1.0.19-R2022.zip`, `BCFier-SP-1.0.19-R2025.zip`
- папки `dist\R2022\`, `dist\R2025\`

Скопируйте содержимое папки года в `%AppData%\Autodesk\Revit\Addins\{год}\` (Revit должен быть закрыт).

**Windows Viewer** — папка `dist\Win\`:

1. Скопируйте содержимое `dist\Win\` в любую папку.
2. Запустите `BCFier.Win.exe`.

Удаление: удалите файлы add-in / Viewer или воспользуйтесь «Установка и удаление программ» (после Setup).

## Что изменилось относительно оригинального BCFier

Оригинальный [BCFier](https://github.com/teocomi/BCFier) архивирован в 2024 году. Этот форк продолжает Revit-часть и автономный Windows Viewer.

### Удалено

- модули Navisworks и Xbim Explorer
- старый monorepo-инсталлер upstream

### Добавлено и существенно доработано

- Revit **2022–2026**, запись BCF 2.1 / 3.0
- граница 3D ↔ плоскости обрезки BCF; с плана/разреза/фасада — камера для чужих клиентов и ссылка на вид Revit ([отклонения от схемы](#отклонения-от-схемы-bcf))
- выделение элементов, сопоставление по Id / IfcGuid / Id в имени
- локализация **ru / en**, табличный режим, колонки комментариев по автору/группе
- [пользовательские поля](#пользовательские-поля) отчёта и протокол HTML/PDF; Excel импорт/экспорт
- несколько снимков на замечание, Windows Viewer, InnoSetup, тесты

## Сборка из исходников

**Solution:** `SP-BCFier.sln`

| Проект | Назначение |
|--------|------------|
| `Bcfier` | Ядро: BCF I/O, WPF UI, локализация |
| `Bcfier.Revit` | Интеграция с Revit |
| `Bcfier.Revit.Standalone` | Add-in (лента и `.addin`) |
| `Bcfier.Win` | Автономный Windows Viewer |
| `tests/Bcfier.Tests` | Тесты |

Конфигурации: **R2022 | R2023 | R2025 | R2026 | Win**.

Для Revit-проектов нужен установленный Autodesk Revit (пути к API в `Directory.Build.props`).

**Revit add-in**

1. Откройте `SP-BCFier.sln` в Visual Studio.
2. Выберите конфигурацию года Revit.
3. Соберите solution. DLL остаются в `bin\R{год}\{tfm}\` (Revit при этом может быть запущен).
4. В Addins по умолчанию ничего не копируется: можно держать установленную версию и подгружать сборку из `bin` через Addin Manager.
5. Чтобы один раз положить add-in в Revit (Revit лучше закрыть):

```text
dotnet build Bcfier.Revit.Standalone -c R2023 -p:DeployToRevit=true
```

или скрипт `dist\R{год}\Install-Standalone.ps1`.

Плагин SP ссылается на `Bcfier` / `Bcfier.Revit` через ProjectReference и забирает DLL из тех же `bin\R{год}\{tfm}\` — отдельный деплой в Addins для этого не нужен.

**Windows Viewer**

```text
dotnet build SP-BCFier.sln -c Win
```

Результат: `dist\Win\BCFier.Win.exe`.

Для отладки Revit укажите `revit.exe` нужной версии как стартовое действие.
